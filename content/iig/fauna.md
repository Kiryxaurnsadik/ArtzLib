### Mutanten: полевой справочник

| Вид | Опасность | Описание |
| :---- | :---- | :---- |
| Слепой пёс | Средняя | Лишён зрения, ориентируется по слуху и обонянию. Охотится стаями. |
| Псевдособака | Высокая | Крупнее и сообразительнее слепого пса. |
| Пси-собака | Высокая | Создаёт иллюзорных двойников. Уничтожать настоящую особь. |
| Плоть | Низкая | Мутировавшая свинья, медлительна. |
| Кабан | Средняя | Толстая шкура, атакует разбегом. |
| Тушкан | Низкая | Мелкий грызун, опасен большой стаей. |
| Снорк | Высокая | Бывший человек в противогазе, передвигается прыжками. |
| Кровосос | Очень высокая | Становится невидимым, питается кровью. |
| Бюрер | Высокая | Карлик с телекинезом, прячется в подземельях. |
| Контролёр | Крайне высокая | Подчиняет волю людей пси-ударом. |
| Излом | Высокая | Человекоподобный мутант с непропорционально длинной рукой. |
| Полтергейст | Средняя | Почти невидим, швыряет предметы. |
| Химера | Крайне высокая | Двухголовый хищник, огромные прыжки. |
| Псевдогигант | Крайне высокая | Массивный мутант, ударная волна при ударе о землю. |

Большинство видов, по данным отдела, связано с экспериментами лабораторий серии X (см. «Лаборатории серии X»).
